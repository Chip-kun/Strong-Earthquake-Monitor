# 強震モニター

リアルタイム地震情報および強震モニタ（KiK-net/K-NET等）の観測データを視覚的に確認・通知するAndroidアプリケーションです。

## 主な機能

- **リアルタイム強震モニタ表示**: 日本全国の観測点における揺れの大きさをリアルタイムで視覚化
- **地震速報・震度通知**: 緊急地震速報や各地の震度情報を迅速にお知らせ
- **詳細マップ & 履歴**: 過去の地震履歴や詳細な震度分布マップの閲覧
- **お気に入り・地域設定**: 自宅や主要な登録地点の警戒レベル設定

## 技術スタック

- **言語**: Kotlin
- **UI**: Jetpack Compose (Material Design 3)
- **アーキテクチャ**: MVVM
- **非同期処理**: Kotlin Coroutines & Flow
