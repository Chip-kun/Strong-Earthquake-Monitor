全国のリアルタイム震度・波形モニターから、各種シミュレーター、安否連絡まで網羅したオープンソースの次世代防災アプリ。

最新リリースのパッケージ（APK/各種ファイル）は GitHub から安全にダウンロードできます。

GitHubでダウンロード (Releases)

充実の防犯・防災機能

🗺️ リアルタイム強震モニタ

地表・地中の微細な震度データを日本地図上にリアルタイム可視化。最寄りのリアルタイム波形モニター（EW/NS/UD）により、100Hzサンプリングの細かな揺れの推移を克明に描画します。

📊 地震情報・履歴一覧

気象庁やP2P地震情報のシステムと連携し、各地で発生した地震履歴を素早くリストアップ。震度、規模（M）、深さ、そして最も重要な「津波の心配の有無」を明瞭に伝えます。

🛡️ 防災マニュアル & 安否連絡

「無事です」などの状況を選ぶだけで、居場所を含んだ連絡用テキストを即座に生成し共有可能。屋内・自動車運転中など、災害時の状況に応じた確実な初動行動指針も常備しています。

🔔 緊急地震速報 訓練シミュレーター

首都直下地震や南海トラフ巨大地震など、様々な災害シナリオを想定したリアルな発令シミュレーション機能を搭載。実際の警報音や音声カウントダウン、波形伝播を疑似体験し、日頃の備えに活かせます。

📱 マイ地震計（端末加速度計）

デバイスに内蔵されている高精度センサーを使用し、今いるその場所の「瞬間加速度（gal）」と「推定計測震度」をリアルタイム測定。家具の転倒目安となるピーク加速度もしっかりホールド記録します。

📦 インストール方法

  1. 上のボタンから GitHub Releases ページにアクセスします。
  2. 最新バージョン（Latest）の Assets 項目を展開します。
  3. 端末に合ったファイル（Androidの場合は .apk など）を選択してダウンロードします。
  4. ファイルを開き、画面の指示に従ってインストールを完了させてください。
